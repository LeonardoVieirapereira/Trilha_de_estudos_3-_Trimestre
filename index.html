📌 1. Definição da Função Quadrática

Uma função é dita quadrática (ou do 2º grau) quando é escrita sob a seguinte forma algébrica:

f(x) = ax² + bx + c     (com a ≠ 0)
  • a: Coeficiente principal (define a concavidade). Não pode ser zero!
  • b: Coeficiente do termo linear (grau 1).
  • c: Termo independente (ponto de intersecção com o eixo Y).

🧠 Desafio de Identificação:

Identifique os coeficientes da função f(x) = -2x² + 4x - 7:

a = -2
b = 4
c = -7

📈 2. Gráfico (A Parábola)

O gráfico de uma função quadrática é sempre uma curva simétrica chamada parábola.

A orientação da sua curvatura é determinada exclusivamente pelo sinal do coeficiente a:

  • Se a > 0: Concavidade voltada para CIMA ◡ (Sorriso).
  • Se a < 0: Concavidade voltada para BAIXO ◠ (Triste).

Cruzamento no eixo Y: A curva sempre intercepta o eixo vertical no ponto (0, c).

🧠 Exercício Prático:

O gráfico da função f(x) = -x² + 3x + 5 tem a concavidade para cima ou para baixo? Onde corta o eixo Y?

• Concavidade para BAIXO (pois a = -1 < 0).
• Corta o eixo Y no ponto (0, 5).

🎯 3. Zeros (Raízes) da Função

Os zeros são os valores de x para os quais f(x) = 0. Correspondem aos pontos em que a curva cruza o eixo X.

Δ = b² - 4ac

x = (-b ± √Δ) / (2a)

Comportamento do Discriminante (Δ):

  • Δ > 0: Duas raízes reais e distintas (cruza o eixo X em 2 pontos).
  • Δ = 0: Duas raízes reais e iguais (toca o eixo X em 1 ponto).
  • Δ < 0: Não possui raízes reais (não toca o eixo X).

🧠 Calcule as Raízes:

Encontre as raízes da função f(x) = x² - 5x + 6.

Δ = (-5)² - 4(1)(6) = 25 - 24 = 1
x = (5 ± √1) / 2
x₁ = (5 + 1)/2 = 3
x₂ = (5 - 1)/2 = 2

➕✖️ 4. Soma e Produto das Raízes

Método ágil para descobrir raízes inteiras sem utilizar a Fórmula de Bhaskara para a equação ax² + bx + c = 0:

Soma (x₁ + x₂) = -b / a
Produto (x₁ · x₂) = c / a

🧠 Desafio Mental:

Determine a soma e o produto das raízes de f(x) = x² - 7x + 10 e encontre os valores de x₁ e x₂.

Soma = -(-7)/1 = 7
Produto = 10/1 = 10
Dois números que somam 7 e multiplicam 10 ➔ x₁ = 2 e x₂ = 5

📍 5. Vértice da Parábola

O vértice V(Xv, Yv) é o ponto de curvatura máxima ou mínima da função.

X_v = -b / (2a)
Y_v = -Δ / (4a)

🧠 Exercício do Vértice:

Ache o ponto do vértice V(Xv, Yv) da função f(x) = x² - 2x - 3.

X_v = -(-2) / (2·1) = 2 / 2 = 1
Δ = (-2)² - 4(1)(-3) = 4 + 12 = 16
Y_v = -16 / (4·1) = -4
Vértice V = (1, -4)

🔝 6. Valor Máximo e Mínimo

O valor extremo da função é o próprio valor de Y_v:

  • Se a > 0: A parábola tem um Valor MÍNIMO (no ponto Y_v).
  • Se a < 0: A parábola tem um Valor MÁXIMO (no ponto Y_v).

🧠 Aplicação:

Uma empresa tem seu lucro dado por L(x) = -x² + 6x - 5. Qual o lucro máximo atingido?

Lucro Máximo é o Y_v:
Δ = 6² - 4(-1)(-5) = 36 - 20 = 16
Y_v = -16 / (4 · (-1)) = 4
Lucro Máximo = 4 unidades financeiras.

📊 7. Conjunto Imagem Im(f)

O Conjunto Imagem representa todos os valores de y (eixo vertical) que a função atinge. Seu limite inicial ou final é sempre o Y_v (Y do Vértice).

Caso a > 0

Existe Valor Mínimo

Im(f) = [ Y_v , +∞ )
{ y ∈ ℝ | y ≥ Y_v }
A função cresce para cima a partir do ponto mínimo.
Caso a < 0

Existe Valor Máximo

Im(f) = ( -∞ , Y_v ]
{ y ∈ ℝ | y ≤ Y_v }
A função vem do infinito negativo e atinge o topo no vértice.

📉📈 8. Crescimento e Decrescimento

A direção da curva altera-se exatamente no ponto X_v (X do Vértice). Ele funciona como o divisor dos intervalos da função:

Comportamento nos Intervalos:

Se a > 0 (Sorriso ◡):
  • 📉 Decrescente: no intervalo ( -∞ , X_v ]
  • 📈 Crescente: no intervalo [ X_v , +∞ )
Se a < 0 (Triste ◠):
  • 📈 Crescente: no intervalo ( -∞ , X_v ]
  • 📉 Decrescente: no intervalo [ X_v , +∞ )

💡 Exemplo Detalhado:

Para a função f(x) = -x² + 6x - 5:

  1. Identificamos a = -1 (como a < 0, ela sobe primeiro e desce depois).
  2. Calculamos o divisor: X_v = -6 / (2 · -1) = 3.
  3. Conclusão: Crescente em (-∞, 3] e Decrescente em [3, +∞).
