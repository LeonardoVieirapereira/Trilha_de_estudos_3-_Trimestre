📌 1. Definição da Função Quadrática

Uma função é dita quadrática (ou polinomial do 2º grau) quando sua lei de formação pode ser expressa como:

f(x) = ax² + bx + c     (com a, b, c ∈ ℝ e a ≠ 0)

a (Coeficiente Principal)

Determina a curvatura da parábola. Nunca pode ser zero, pois anularia o termo quadrático, transformando a função em linear.

b (Coeficiente Linear)

Determina a inclinação com que a curva corta o eixo Y (se subindo ou descendo). Pode ser igual a zero.

c (Termo Independente)

É a ordenada do ponto onde o gráfico intercepta o eixo Y: (0, c). Pode ser zero.

🧪 Tipos de Funções (Completas e Incompletas):

  • f(x) = 3x² - 5x + 2 ➔ Completa (a = 3, b = -5, c = 2)
  • f(x) = -x² + 9 ➔ Incompleta (a = -1, b = 0, c = 9)
  • f(x) = 4x² - 8x ➔ Incompleta (a = 4, b = -8, c = 0)

🧠 Desafio Prático:

Quais são os coeficientes de f(x) = 5 - x² + 2x?

Organizando na ordem correta (-x² + 2x + 5):
• a = -1
• b = 2
• c = 5

📈 2. Gráfico (A Parábola)

O gráfico de toda função quadrática é uma curva contínua e simétrica chamada parábola.

a > 0 (Positivo)

Concavidade voltada para CIMA ◡

A curva possui um ponto de valor mínimo.

a < 0 (Negativo)

Concavidade voltada para BAIXO ◠

A curva possui um ponto de valor máximo.

🔍 O papel do coeficiente b no gráfico:

  • b > 0: A parábola cruza o eixo Y subindo.
  • b < 0: A parábola cruza o eixo Y descendo.
  • b = 0: O próprio eixo Y é o eixo de simetria da parábola (o vértice fica no eixo Y).

🧠 Exercício de Análise Visual:

Na função f(x) = 2x² - 4x - 6, qual o comportamento da curva no eixo Y?

• Como a = 2 (> 0), concavidade para cima.
• Como b = -4 (< 0), cruza o eixo Y descendo.
• Como c = -6, intercepta o eixo Y exatamente no ponto (0, -6).

🎯 3. Zeros (Raízes) da Função

Os zeros ou raízes de uma função quadrática são os valores de $x$ que tornam $f(x) = 0$. Geometricamente, são as coordenadas onde a parábola cruza o eixo horizontal $X$.

1º Passo: Calcula-se o Discriminante (Δ)
Δ = b² - 4ac

2º Passo: Aplica-se a Fórmula de Bhaskara
x = (-b ± √Δ) / (2a)

Δ > 0

2 Raízes Reais e Distintas
A parábola corta o eixo X em dois pontos distintos.

Δ = 0

2 Raízes Reais e Iguais
A parábola tangencia (toca em apenas 1 ponto) o eixo X.

Δ < 0

Nenhuma Raiz Real
A parábola flutua sem tocar o eixo X.

🧠 Exercício Passo a Passo:

Encontre as raízes de f(x) = x² - 6x + 8.

1. Identificar coeficientes: a = 1, b = -6, c = 8
2. Δ = (-6)² - 4(1)(8) = 36 - 32 = 4 (Δ > 0, duas raízes)
3. x = (-(-6) ± √4) / (2·1) = (6 ± 2) / 2
• x₁ = (6 + 2)/2 = 4
• x₂ = (6 - 2)/2 = 2

➕✖️ 4. Soma e Produto das Raízes

O método de Relações de Girard permite determinar as raízes mentalmente sem necessitar da Fórmula de Bhaskara para equações do tipo $ax^2 + bx + c = 0$.

Soma das Raízes (S) = x₁ + x₂ = -b / a
Produto das Raízes (P) = x₁ · x₂ = c / a

💡 Dica para quando a = 1:

A equação fica na forma x² - Sx + P = 0. Procuram-se dois números que multiplicados resultem em c e somados resultem no oposto de b.

🧠 Desafio de Raciocínio Rápido:

Descubra as raízes de f(x) = x² - 9x + 20 por Soma e Produto.

• Soma (S) = -(-9)/1 = 9
• Produto (P) = 20/1 = 20
Procurando dois números que somam 9 e multiplicam 20:
➔ x₁ = 4 e x₂ = 5

📍 5. Vértice da Parábola

O vértice $V(X_v, Y_v)$ representa o ponto onde a função muda seu sentido (de decrescente para crescente ou vice-versa).

Coordenada X do Vértice:   X_v = -b / (2a)

Coordenada Y do Vértice:   Y_v = -Δ / (4a)

X do Vértice (Xv)

Indica o ponto no eixo X onde ocorre o valor extremo. Corresponde à média aritmética das raízes: (x₁ + x₂)/2.

Y do Vértice (Yv)

Indica o valor extremo em si (a altura máxima ou mínima) atingida pela função no eixo Y.

🧠 Exercício Guiado:

Ache o vértice V(Xv, Yv) de f(x) = 2x² - 8x + 6.

1. Coeficientes: a = 2, b = -8, c = 6
2. X_v = -(-8) / (2·2) = 8 / 4 = 2
3. Δ = (-8)² - 4(2)(6) = 64 - 48 = 16
4. Y_v = -16 / (4·2) = -16 / 8 = -2
➔ Vértice V = (2, -2)

🔝 6. Valor Máximo e Mínimo

Os valores de máximo e mínimo são essenciais em problemas de otimização (área máxima, custo mínimo, lucro máximo).

Ponto de MÍNIMO (a > 0)

O valor mínimo da função é Y_v = -Δ / (4a) e ocorre na posição X_v = -b / (2a).

Ponto de MÁXIMO (a < 0)

O valor máximo da função é Y_v = -Δ / (4a) e ocorre na posição X_v = -b / (2a).

📦 Aplicação Prática:

A trajetória de um projétil é modelada por h(t) = -5t² + 20t, onde h é a altura em metros e t o tempo em segundos.

Perguntas: a) Qual a altura máxima atingida? b) Em quanto tempo atinge essa altura?

• a) A altura máxima é o Y_v:
Δ = 20² - 4(-5)(0) = 400
Y_v = -400 / (4 · (-5)) = 20 metros.

• b) O tempo para atingir a altura máxima é o X_v:
X_v = -20 / (2 · (-5)) = 2 segundos.

📊 7. Conjunto Imagem Im(f)

O Conjunto Imagem representa todos os valores de y que a função atinge. Seu limite inicial ou final é sempre o Y_v (Y do Vértice).

Caso a > 0

Existe Valor Mínimo

Im(f) = [ Y_v , +∞ )
{ y ∈ ℝ | y ≥ Y_v }
Caso a < 0

Existe Valor Máximo

Im(f) = ( -∞ , Y_v ]
{ y ∈ ℝ | y ≤ Y_v }

📉📈 8. Crescimento e Decrescimento

A direção da curva altera-se exatamente no ponto X_v (X do Vértice). Ele funciona como o divisor dos intervalos da função:

Comportamento nos Intervalos:

Se a > 0 (Sorriso ◡):
  • 📉 Decrescente: no intervalo ( -∞ , X_v ]
  • 📈 Crescente: no intervalo [ X_v , +∞ )
Se a < 0 (Triste ◠):
  • 📈 Crescente: no intervalo ( -∞ , X_v ]
  • 📉 Decrescente: no intervalo [ X_v , +∞ )
